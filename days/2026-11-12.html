AWS releases an official local emulator, built largely by AI agents

Amazon Web Services has published an official emulator that lets developers run tests against a local copy of many AWS services, with no paid account or API key. It is written in Rust and, according to the write-up, was built by a large group of AI agents that made 29,684 commits in its first three weeks; AWS executive Swami Sivasubramanian described how in a guest post on Werner Vogels' blog. It currently needs Docker on macOS and Windows, and a single-binary build would make it far easier to use in test suites.

Google launches Gemini Decisions API: calibrated yes/no and multiple-choice answers in one pass

Google released an API endpoint for fast closed-set decisions such as tool selection, policy checks, model routing and content grading. It runs a new model, gemini-decision-1, that scores candidate answers in a single forward pass instead of generating text, returning probabilities for each answer. One request can carry up to 1,000 questions over a shared multimodal input (text, images, audio, video, PDFs up to 256K tokens). Pricing is $0.10 per million input tokens and nothing for output, with the shared input billed once per request; Google reports 150–250 ms latency. It is available in the Gemini API and AI Studio, with OpenRouter, LangChain, LiteLLM and Vercel integrations rolling out.

Unsloth adds Qwen3.8-27B GGUFs and big image-model memory savings

Unsloth's latest beta ships Dynamic v3.1 GGUFs of Qwen3.8-27B for local use, plus faster chat streaming and HTML/PDF chat export. Image generation gets cheaper: FLUX.2 and FLUX.3 use 36–43% less VRAM when decoding, INT8/FP8 image models now run on older NVIDIA GPUs such as the T4, and LTX-2.5 FP8 fits on 24 GB cards. Claude Code and Codex can also run against MLX models on Mac, and model.generate() is 2–8x faster on T4 for FastModel models.

DeepMind's AlphaGenome 2 predicts DNA effects cell type by cell type

AlphaGenome 2 is conditioned on a target tissue or cell type and predicts gene activity for that one condition, trained on over 100 million single-cell profiles across 68 tissues. It adds DNA methylation as a readout and can adapt to new cell states without retraining. On an immune-cell dataset it identified about twice as many causal variants (30% vs 16%) as the original model fine-tuned on single-cell data. It is available for non-commercial research through the AlphaGenome API; it is not validated for clinical use.

A2UI 1.0: Google's open protocol for agent-generated interfaces goes stable

The first stable release of A2UI lets AI agents answer with interactive screens (forms, confirmations, charts) that each app renders with its own native components. 1.0 adds bidirectional function calls, accessibility support and extensions, with renderers for React, Angular, Lit, Flutter, SwiftUI and Jetpack Compose, and new TypeScript and Dart agent SDKs. Atlassian, ByteDance, Alation and Bloomberg are named adopters, and Gemini Notebook already uses it.
