NVIDIA Vera Rubin sweeps MLPerf Training v6.1 in its debut

NVIDIA's Vera Rubin platform swept every MLPerf Training v6.1 benchmark and was the only platform to submit results across all of them. Vera Rubin NVL72 delivered up to 2x the per-GPU performance of GB300 NVL72, and DeepSeek-V3 training scaled from 256 to 1,024 GPUs at about 97% efficiency, cutting time to train from 16 minutes to about four. In its first MLPerf Endpoints submission NVIDIA also claims more than 10x generational gains in throughput per watt for agentic inference, including a provisional Kimi K3 result of over 10x versus GB300 NVL72 at the same response speed. The Kimi K3 figure is still pending MLCommons verification, and these are vendor-reported submissions.

vLLM v0.34.0 adds ten models and turns on the extensible KV cache by default

vLLM v0.34.0 adds ten new models, including Mistral Large 4, MiniMax-M3.1-Flash and NVIDIA Nemotron-3.5-Transcribe. The extensible KV cache is now on by default, sizing the cache from memory left free after warmup, and Model Runner V2 is the only GPU runner. The release reports large Blackwell and MI355X speedups, such as up to 1.95x faster decode for Step5 on GB200 and 1.6x higher throughput for GLM-5.3-Flash. Several changes can break existing setups: the default block size is now 64, ROCm 7.2 images are no longer published, huggingface_hub 2.0.0 or later is required, and QuTLASS, fp_quant and Marlin W4A8 are removed. Only the first part of the release notes was read.

Hugging Face routes open-weight inference through OpenRouter

Open-weight models on the Hugging Face Hub can now be called with a Hugging Face token through one API, with OpenRouter choosing the provider per request by price, speed and reliability and retrying on another provider if one fails. Existing code keeps working, and model pages gain provider and metrics tabs, per-provider spend breakdowns and settings to disable providers. The trade-off: developers can no longer bring their own provider API keys for language models.

NVIDIA announces Rubin HPC GPU and Vera CPU platform at SC26

At SC26 NVIDIA announced Rubin HPC, a new GPU in the Vera Rubin platform aimed at simulation and data processing for science and engineering. It lists more than 50,000 CUDA cores, a sparse data acceleration capability and seventh-generation NVLink, gives no FP64 figures, and is expected in 2028. NVIDIA also announced a rack-scale Vera CPU platform for HPC, built around its first fully custom data center CPU and its HPC networking. Both are roadmap announcements, not shipping products.

Tencent Hy4 Flash appears on OpenRouter at about $0.035 / $0.14 per million tokens

Tencent's Hy4 Flash is listed on OpenRouter through Tencent Cloud at $0.035 per million input tokens and $0.1405 per million output tokens, passed through without markup. The listing supports streaming, tools, structured outputs and reasoning settings. Context length is not stated on the page and no benchmarks were found, so capability is unverified; the price is as listed by the router.
