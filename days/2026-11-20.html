Claude solves two open problems in black hole physics

Anthropic reports that Claude, run as a group of copies of itself, settled two open problems in theoretical physics. The first is the Hawking-Page transition in N=4 super Yang-Mills theory, a 2003 calculation never completed: the transition is abrupt at weak coupling, and the post argues it most naturally stays abrupt at all couplings. The second is the 3D-gravity modular bootstrap, where Claude found an exact ceiling of about c/9.1266 on the lightest black hole's mass and showed this method cannot lower it further. The bootstrap result was checked in the Lean proof assistant, reproduced independently by two other agents and reviewed by a physicist. Anthropic notes neither result describes our universe directly or has practical applications.

TensorRT-LLM 1.3.0 adds preview Rubin support and drops the TensorRT backend

NVIDIA's TensorRT-LLM 1.3.0 adds preview support for the Rubin GPU (SM107), validated on Vera Rubin, with DeepSeek-V4 and Kimi K3 running on Blackwell and Rubin, including multimodal and multi-node Kimi K3 serving. It also adds Qwen3.5/3.6/3.8-Flash-Next, MiniMax-M3, GLM-5.x and Gemma 4, prefix caching for Mamba hybrids, on-by-default prefix-aware scheduling and KV Cache Manager V2. It is a breaking release: the TensorRT backend and trtllm-build are gone (PyTorch is the only backend), along with the C++ Executor, two-model speculative decoding and AutoDeploy, and the /perf_metrics endpoint is replaced by a response header. Anyone on the old build path has to migrate.

Gemini API adds Tool Retrieval so agents load tool schemas on demand

Tool Retrieval, in preview in the Gemini Interactions API, lets an agent hold a large tool library and load a tool's parameter schema only when a task needs it. Developers add a tool_search tool and mark held-back tools with defer_loading: true; the model still sees each tool's name and description. Search runs server-side with no index to build (client-side execution is possible at one extra round trip per search). There is no separate fee beyond standard token rates plus a small fixed block, and loaded schemas count as input for the rest of the conversation. It works with Gemini 3.6 and later, including all Gemini 4 models, and remote MCP servers.
