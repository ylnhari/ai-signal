# AI Signal

A daily curated brief on AI infrastructure — model releases, inference engines, open weights, hardware.

Live: https://ylnhari.github.io/ai-signal/

Generated by a private editorial pipeline; this repo holds only the published page.

## Gates

- `python scripts/check_bench_freshness.py` — fails if any bench page is overdue for its AGENTS.md-documented weekly recheck.
- `python scripts/check_links.py` — fails if any internal href/asset path doesn't resolve to a real file.
